# Architecture decision records

One file per decision: `NNNN-short-title.md`, numbered in order, never renumbered. A superseded ADR stays and links to the one that replaces it.

```markdown
# NNNN. Title

- Status: proposed | accepted | superseded by NNNN
- Date: YYYY-MM-DD
- Issue: #N

## Context
What forced the decision, including measurements.

## Decision
What we chose.

## Consequences
What becomes easier, harder, or must now be done.
```
